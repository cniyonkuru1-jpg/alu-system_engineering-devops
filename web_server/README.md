# Web server project

This directory contains the Web server project deliverables for the ALU system engineering and DevOps curriculum.

- `0-transfer_file`: transfers a local file to a remote user's home directory with strict host key checking disabled as required by the task.
- `1-install_nginx_web_server`: installs Nginx and serves the required Holberton School text on port 80.
- `2-setup_a_domain_name`: pending a real registered root `.tech` domain and its DNS A record; this answer must contain the domain only.
- `3-redirection`: installs Nginx and configures the permanent `/redirect_me` redirect.
- `4-not_found_page_404`: configures the redirect and illustrated custom 404 page.
- `5-design_a_beautiful_404_page.html`: standalone illustrated 404 page for the manual design review.

The domain task needs a student-owned domain and registrar access; the answer must not contain a made-up domain.
